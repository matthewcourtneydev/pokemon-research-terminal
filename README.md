# Pokémon Research Terminal

A modern Pokémon research platform built with React, TypeScript, Fastify, and PostgreSQL.

## Features

- 🔍 Advanced Pokédex
- 🧬 Collection Manager
- ⚔️ Team Builder
- 📊 Raid Planner
- ⭐ Favorites
- 📈 Battle Analysis

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- React Router
- TanStack Query
- Zustand

### Backend
- Fastify
- Prisma
- PostgreSQL
